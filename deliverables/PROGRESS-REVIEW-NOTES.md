## 1. ZIKEY 字鑰

[0:00–1:00 | 60 sec] I am Lin Wei-De, W16157093. ZIKEY helps Mandarin self-learners decide what character to learn next. A vocabulary list gives an order, but does not explain the value of a character for what I already know. My prototype connects characters through documented components, reveals words that become readable, and lets the learner change the recommendation goal. ## 5. Recommendations expose their evidence

[4:00–5:15 | 75 sec] Native chart data is computed from core.py for the sample learner with 21 known characters and Default weights, filtered to the 青 family. Prevalence counts pilot entries containing a character. Reuse counts other learning characters using it as a named leaf in flattened IDS. Unlock counts entries whose remaining unknown character set contains only that character. Heat is zero unless explicitly enabled; simulated heat is separately labelled. Each signal is divided by the maximum among all currently unknown characters and multiplied by normalized weights. Scope filters the global scores, so family bars remain comparable. Default weights are 35,25,40,0; Read more is 25,15,60,0; See structure is 15,65,20,0. The model does not train or set these weights: Ollama selects up to two evidence sentences from a supplied set. Invalid output falls back to a labelled template. The distinct contribution is inspectable learner-relative scoring and interactive steering; similar graph tools also offer learned marks and word unlocks, so I do not claim those alone are novel.

## 8. Roadblocks, decisions and next work

[8:45–9:40 | 55 sec] The most important limitation is language-data ambiguity. I retained dictionary alternatives and labelled unresolved matches instead of letting the model invent a gloss. Expert checking of Taiwanese readings and ambiguous senses comes next. The graph is intentionally bounded: radical grouping organizes the overview while documented phonetic families support focus, and typed visual edges stay separate from structural scoring. Browser QA found Plotly document CSS did not cross the Streamlit component shadow root; explicit positioning now keeps all SVG layers inside the coverage view. The local model has noticeable first-request latency, so results are cached and failure is explicit. Next I will validate senses, obtain licensed corpus frequency, and ask3–5 learners to perform the proposal tasks T1–T3, recording completion, time and comments. This usability check will not establish long-term learning effectiveness. ALS remains deferred until sufficient multi-user data exists.

## Q&A (2 minutes)

- Does this prove faster learning? No. It verifies a functional pipeline and in-sample vocabulary coverage only.
- Does the LLM rank characters? No. The displayed weighted score ranks; the model selects supported explanations.
- Why these data limits? A bounded, traceable pilot makes the core task demonstrable. Missing and ambiguous senses are explicit.
- Is prevalence frequency? No. It counts pilot vocabulary entries containing each character.
