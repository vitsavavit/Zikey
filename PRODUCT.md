# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Mandarin self-learners from zero to intermediate, primarily international students. Instructors
reviewing the Information Visualization progress project are a secondary presentation audience.

## Product Purpose

Connect pinyin, character structure and readable words, and let learners inspect and steer which
unknown character to learn next. Success is explaining a recommendation and its word unlocks.

## Capabilities and Constraints

Preserve A network, B explanation/ranking and C coverage. Use the existing local Streamlit,
D3, Plotly, Python/NetworkX and Ollama implementation. No paid APIs. The current pilot has
290 characters and 450 vocabulary entries. Scores are deterministic; the local LLM selects
supported evidence. Vocabulary coverage is an in-sample proxy, not text comprehension.

## Brand Commitments

ZIKEY 字鑰. English interface and Traditional Chinese. User confirmed a hybrid galaxy overview
that zooms into groups/characters for learning, inspired by the supplied galaxy image and
Hanzi Constellation. The user subsequently confirmed a contemporary reference-book visual identity:
warm paper, navy binding header, clear type and subtle rules. Preserve the galaxy interaction and
proposal A/B/C information architecture; do not restore the dark dashboard theme. Explain encodings.

## Evidence on Hand

Original proposal slides, supplied Claude planning chat, progress-review instructions,
preserved TOCFL/Make Me a Hanzi/CC-CEDICT snapshots, QA plan review, existing tests and prototype.
No learner-study evidence or corpus frequency file has been supplied.
